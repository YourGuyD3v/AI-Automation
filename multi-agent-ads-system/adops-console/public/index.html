Connection

Point this console at your n8n webhook. Settings are stored in this browser only.
Deployed on Vercel these default to the built-in proxy routes /api/message and /api/status, which forward to the n8n URLs in your environment variables. No CORS setup needed on n8n. Override below only to call n8n directly.
Sent as Authorization.

What the console posts

POST /webhook/adops/message
{
  "project_id": "proj_k3f9a2",
  "action": "message" | "brief" | "approve"
             | "request_changes" | "revision",
  "stage": "intake",
  "message": "free text from the user",
  "brief": {
    "project_name": "", "product": "",
    "target_audience": "", "platform": [],
    "duration_seconds": 30, "objective": "",
    "tone": [], "assets": [], "constraints": ""
  },
  "timestamp": "2026-09-16T10:00:00Z"
}

What it expects back

{
  "project_id": "proj_k3f9a2",
  "stage": "creative",
  "status": "CREATIVE_PENDING_APPROVAL",
  "reply": "text shown in the chat",
  "approval": {
    "required": true,
    "title": "Creative concept",
    "fields": { "Big idea": "…", "Hook": "…" }
  },
  "progress": {
    "scenes_done": 3, "scenes_total": 6,
    "assets": 14, "qc_attempts": 1
  },
  "video_url": null
}
Any field can be omitted. reply alone is enough to get a working chat loop; add the rest as each workflow comes online.
